Getting Started

Installation

Get up and running in seconds. No build tools, no dependencies — just a single CSS link.

CDN (Recommended)

Add the following <link> tag to your HTML <head>:

HTML — jsDelivr CDN
<!-- Iconic Framework v2.0.0-alpha --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/junaidprodeveloper/Iconic@2.0.0-alpha/iconic-framework.css">

Multiple Files

jsDelivr Combine API
<!-- Combine multiple files in a single request --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/combine/gh/junaidprodeveloper/Iconic@2.0.0-alpha/iconic-framework.css, gh/junaidprodeveloper/Iconic@2.0.0-alpha/iconic-icons.css">
